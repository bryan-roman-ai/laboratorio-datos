# Laboratorio de datos — Bryan Román

Análisis económicos reproducibles sobre Ecuador y América Latina: datos públicos (Banco Mundial, NOAA, Atlas de Complejidad Económica de Harvard, arXiv), código abierto y comprobaciones automáticas en cada estudio (reproducción independiente, permutaciones o bootstrap, dejar un país fuera, definiciones alternativas).

Bryan Román · Economista (UTPL), Magíster en Transformación Digital (UNIR) · Cuenca, Ecuador

## Estudios

- [El Niño y la agricultura de América Latina, país por país](nino-latam-agro/) — ¿Cuánto cambia el crecimiento agrícola de cada país latinoamericano cuando El Niño se intensifica, y depende de si exporta alimentos?

Aviso: análisis personal con fines educativos; no es asesoría financiera ni opinión de ninguna institución.
